# ProFPS

ProFPS is a Minecraft 1.21.11 Fabric client-only mod that provides an in-game control panel for combat assists, CrystalPVP helpers, and hitbox visualization.

## Features

- Right Shift opens the normal NovaClient panel. A fire-marked **Modes** entry directly below Configs, with a themed **NEW** badge, slides the main UI upward and raises Combat Modes from below. Sword, Axe, and Mace remain in one compact responsive row with per-mode keybind setters, inset semi-transparent LT5→HT1 outline rails, contained hollow drag knobs, pronounced drag trails, and an animated red HT1 tracer. Advanced settings stay in their separate popups; Modes is opened only through this sidebar entry.
- Nova uses one responsive virtual canvas for the full panel, Modes, popups, text, icons, edges, scissor regions, and mouse hit areas. Automatic UI Size is enabled by default and recalculates on every window/GUI-scale change so the complete layout stays inside the viewport without sidebar or card overlap. Settings also provides a manual 50–140% size control; oversized requests are safely capped to the current window and the applied percentage is shown live.
- **Sword Mode** (default tier HT4, mode off by default) coordinates Aim Assist, Strafe Assist, Auto Sprint, and Triggerbot without rewriting the standalone module configuration. Optional AI Bot is off by default; enabling it gives Sword AI exclusive ownership of aim/movement while keeping Triggerbot on the same legal-hit path. Auto Sprint never creates forward movement: after a short tiered cadence it adds only the vanilla sprint input while the player is already holding forward, and yields to manual retreat/sneak, crit movement, hunger, collision, fluids, and unsafe footing. A confirmed hit schedules a brief real-input backward or back-diagonal spacing step on the next plausible keyboard tick, then sprint can re-engage only if the player continues forward. When collision, footing, hunger, and player input make it safe, Triggerbot converts a sweep-prone grounded sword cycle into a full-charge, sprint-classified single-target hit through real W+sprint input; unsafe windows wait/re-arm instead of forcing movement, and a small 4.5% natural-sweep allowance remains.
- **Axe Mode** (default tier LT4) combines melee aim, shield-aware Axe Stun, improved bow/crossbow ballistic tracking, and a bounded Axe→best-hotbar-sword continuation. The post-stun trigger window is tied to the exact stunned player and is consumed by one confirmed sword hit; it never enables the standalone Triggerbot globally.
- **Mace Mode** (default tier LT3) coordinates Auto Mace, mace aim, Stun Slam, and Auto Breach Swap. Above LT3, Pearl Catch tracks the local player's own pearl, solves upward/horizontal/descending trajectories, visibly aims on the mouse grid, throws one real wind charge only along a clear route, and restores the previous slot on the following tick.
- Tier profiles alter reaction, dwell, target retention, movement, projectile solving, and aim characteristics under the hood while retaining nonzero hesitation/tremor and the same legality gates. One pre-movement action owner coordinates the mode controllers, Expanded Hitbox, and Auto Creeper so they cannot send competing attacks, uses, or hotbar sequences in the same tick.
- Low, Medium, High, Max, and Extreme optimization modes.
- Predictive render/simulation distance tuning.
- Runtime entity distance, graphics, cloud, and particle pressure control.
- Particle admission control that drops low-value particles before vanilla allocates/renders them.
- Foveated entity and block-entity render culling that protects close/on-screen objects while shedding distant low-priority work.
- Predictive chunk rebuild pacing that defers far off-axis rebuilds during pressure spikes.
- Frame-budget scheduler that can pace chunk uploads, translucent sorting, shadows, labels, weather, and cloud passes when a frame overruns budget.
- Camera-path prediction that looks ahead while sprinting/flying so the scheduler keeps work in the direction the player is moving.
- Base Heat radar HUD with rotating sweep, range rings, and heat-colored contacts.
- Chunk Finder paints flagged bases as flat see-through chunk pads at the deepest leaked evidence (y=0 by default). Touching chunks merge into one clean region — a single flat sheet and one perimeter outline in one unified tier colour, so a base never reads as ugly nested red-in-yellow boxes. A hard-evidence gate keeps natural worldgen (villages, mineshafts, dungeons, ore, lava light) from flagging, an explosion-burst rejector ignores TNT/crystal blasts, and on-site grief hardware with no intact storage is dropped — so a blown-up PvP fight is never mistaken for a base.
- Base-finding aids: see-through tracer lines fan out from the crosshair to each region (one per base), floating distance + evidence labels ("214m · 3chest 2snd") pin above each region, and `/nova bases` lists every archived base with click-to-copy coordinates.
- Chunk Finder **Experimental** mode (off by default): aggressive passive side-channel mining. Anti-xray rewrites the block palette but never the block-entity list, so this reads the EXACT positions of every container/spawner in the masked deep zone of loaded chunks (pinning real loot through the deepslate mask without anyone touching it) and runs a finer, lower-floor light-leak scan that catches small dimly-lit hidey-holes the default scan misses. Strictly passive — it only reads packets the server already sends.
- Instant results: a live-signal fast path scans a chunk the same tick a leaked sound or deep block update arrives, activation bursts cover the whole radius immediately, and detection overlays render from a cached score order with a single see-through line/fill batch per frame.
- Slow module: a purely client-side held-item animation slowdown. Mining, attacking, and block placing look far slower on your own screen while the server still registers every hit and break at full speed.
- Combat → **Triggerbot** — softly pre-tracks a visible player under the block-aware ray for the final 0.45 blocks before legal reach, then still requires both a fresh vanilla ray and vanilla's actual crosshair before every attack. This lets the 8–55 ms distance-aware reaction, short settle, cooldown, and genuine forward+sprint anti-sweep input overlap while an opponent approaches instead of stacking after they enter three blocks. Sword/axe cooldown thresholds are sampled once per attack cycle (83–93% sprinting, 88–93% walking at the defaults), closing-window follow-ups use a bounded short commit beat, axes retain their jittered 100–140 ms post-ready beat, and brief aim/range flickers retain preparation for 160 ms. A sweep-prone grounded sword cycle gets one applied, collision-checked soft-prep attempt and at most one applied hard-contact retry through the real movement-input path before the vanilla swing, preventing auto-chase; rejected unsafe windows do not consume those attempts. A small 4.5% once-per-cycle allowance leaves an occasional naturally eligible sweep unchanged. Unsafe preparation never forces movement or rerolls toward a sweep. Crit Timing waits only in a real descending crit window and yields to normal attacks in water, lava, blindness, levitation, slow falling, vehicles, gliding, flight, or while sprinting. **Sneak Disable** treats crouching as manual do-not-attack intent.
- Combat → **Hitboxes** — draws smooth, interpolated player bounding boxes with dedicated no-depth rendering, so both the outline and optional translucent fill stay visible through blocks, entities, and walls. Its expanded module panel provides exact Red/Green/Blue sliders plus separate outline opacity, fill opacity, and line-width controls.
- Freecam flies a fully detached camera on the render clock (frame-time integration + exponential velocity smoothing, so it's glassy at any fps) while the body stands frozen with its rotation re-pinned every tick — nothing the mouse does while flying reaches the server. Scroll wheel live-trims flight speed (hotbar untouched), sprint doubles it, and releasing the keys stops dead. With Tunnel running, the body keeps mining while you scout.
- Tunnel digs a strict straight 1×2 line (no side-wall mishits), recovers from cave drops by stair-carving back to its line, and never strands itself — when truly boxed in it climbs straight up and out instead of giving up.
- Instants section — humanized, low-detection game-mechanic optimizers: **BreakOn** (auto-swaps to the optimal tool for whatever block you look at — shovel/axe/pickaxe, never a block or your hand unless Hand Use is on — and mines it, no rotation; its **Certain Blocks** option opens an animated dropdown with a live block search and checkboxes so it only targets the blocks you tick), **Autoclicker** (jittered-CPS left/right clicking through the real click handlers — a configurable target CPS up to 20 (the real ceiling: it fires one click per game tick, and 20 is already above human and plenty for old PvP) with a Gaussian spread and the occasional hesitation, plus Hold mode to only fire while the button is down; it steps aside for the ~2-tick knockback impulse when you're hit so it doesn't sprint-reset/fight the knockback, then clicks on), **Fastbreak** (modest, jittered break-speed boost), **AutoTool**, **FastPlace**, **AutoSprint**, and **AutoWalk**. Every module (in every section) can be bound to a key right in the panel.
- Extra Assists → **Clutch** — an emergency save when you're falling into a drop you won't walk off of. When you get knocked off into the void, or fall off a tower/ledge with no floor right under you, it places a block on the way down to catch you — but only as a panic save: it never rotates your view, never speeds placement up, fires only while you're genuinely over a drop (no floor within a few blocks below — so a tower fall counts, not just a 16-deep void column) and only if your own crosshair is on a reachable catch face under you, and it's hard-capped at two blocks per fall (with a cooldown) so it can't be abused to spam-bridge off repeated hits. The reaction is humanized but **fast** — the window is tiny, so a near-reflex jittered flick is what lands the save. To make it actually fire in a panic it has a **silent catch**: if your crosshair isn't on a catch face it places a block under your feet against the nearest reachable solid block — the pillar under you, or the wall/tower you're falling beside — still with no rotation. Only fully open void with nothing in reach can't be saved (no mod or human can place there).
- Extra Assists → **Anti Fireball** — deflects incoming fireballs (the bedwars throwable-fireball entity) with a sword, for you. When one is on a path that would pass close to you, it smoothly turns your head onto it (humanized, frame by frame), swaps to a sword from your hotbar, and the moment it's aimed and in reach it swings — a melee hit sends the fireball off the way you're looking, so aiming AT it sends it back where it came. It only acts when a fireball is genuinely headed at you and you have a sword, and puts your original slot back once nothing's incoming. (Symbol: the fire charge.)
- Extra Assists → **Height Clutch** — a fall-save built around a held item instead of a placed block, so it works on open drops. It only ever acts when the right item is in your **hotbar** and you're genuinely falling. Neither mode ever moves your view. With a **water bucket** (preferred) it MLGs for you: looking down onto solid ground, it switches to the bucket, places the water below you, waits until you've landed in it, pauses a human beat, scoops the water back up, and switches your hand back to what you were holding — over frames, not in one jump (and it never picks the water back up the instant you land, which would read as a bot). Because it doesn't aim for you, you have to be looking down for the placement to land where you fall. With **ladders** instead, if you're falling beside a wall, it silently places a ladder against the nearest reachable wall block in your path — recomputed at the moment of placement so on a tower it grabs a block you can still reach as you fall, not just the last one — so you catch and climb to safety. (Symbol: the ladder.)
- Extra Assists → **Ping Spoofer** — makes the server report whatever **Ping** (ms) you set. The server measures your latency only by how long you take to answer its KeepAlive packets, so this holds *that one reply* (and only it — your movement and everything else flow normally, so there's no real lag) for your chosen delay, and the round-trip the server times comes back as the spoofed ping. The held reply always goes out well within the server's timeout, and instantly if you switch it off, so it never disconnects you. (Symbol: the compass. Note: on servers with lag compensation a higher ping can shift hit registration in your favour, so it's not purely cosmetic.)
- Extra Assists → **Ping Equalizer** — instead of a fixed number, matches your reported ping to the **player you're fighting**, so neither side gets a lag-compensation edge in the trade. Every time you hit a player they become your opponent for a few seconds; while that's live it reads their ping from the tab list and feeds it into the same KeepAlive-hold engine as the Ping Spoofer, so the server times your round-trip as *their* ping. When the fight goes quiet (no hit within the window) or their ping isn't known, it stops matching and your real ping shows through. Because the server only re-measures latency on its periodic KeepAlive, a freshly matched ping takes effect on the next one — same inherent delay as any ping spoof. If both this and the Ping Spoofer are on, the Equalizer wins while you have a live opponent and the fixed value covers the gaps. (Symbol: the recovery compass.)
- Extra Assists → **Scaffold** — placement-only: it never changes camera yaw/pitch, movement input, or jump input. It reads the player’s real feet, input, and velocity, then follows forward, backward, sideways, or diagonal movement at the physical block edge. Exact side-face bridging is supported, while the normal no-crouch posture can look steeply down at the supporting block; the nearest movement-aligned foot edge selects the single outward face. The player’s own jump can place upward beneath their feet for towers or moving stairs, but Scaffold never initiates that jump. Failed interactions are not counted, and placement still requires a held block, reachable support, and a real drop rather than ordinary terrain. Settings expose only Sneak Only and Speed.
- Classics → **Flight** — the classic creative-style fly. WASD moves you the way you're looking, jump rises, sneak descends, and you hover when you press nothing; fall damage is cleared while it's on, and a **Speed** meter (1–10) sets how fast. It's purely client-side motion: in singleplayer or on a server that allows flight it just works; a survival server's movement anticheat will see motion the physics forbid and rubber-band you. It's an honest fly, not an anticheat bypass.
- Classics → **Spam** — repeats a chat message you type (in-panel text field, default *Novaclient Is The Best Client*) on a **Speed** (1–10) timer with a little jitter so it isn't a perfect metronome; a message starting with `/` is sent as a command. It pauses while any menu is open, and the top rate is bounded to something a server will actually accept (servers rate-limit / mute chat spam).
- Classics → **Boat Fly** — fly a boat you're riding, even over solid ground. While you're in a boat it drives the boat's position straight from your keys (WASD relative to where you look, jump up, sneak down), fully overriding the boat's gravity and water physics — press nothing and you hover, press keys and you cruise; a **Speed** meter (1–10) sets how fast. Purely client-side, so it just works in singleplayer / on a permissive server and a movement anticheat will rubber-band the impossible boat motion. (Symbol: the oak boat.)
- Classics → **Teleporter** — right-click a block you're looking at to teleport onto it. On each fresh right-click it raycasts where you aim (up to the **Range** you set) and moves you to the face you clicked. Purely client-side — it just sets your position and lets the next packet carry it — so in singleplayer / on a permissive server it works, and a movement anticheat rubber-bands the jump (hence "tries to"): short hops land reliably, long ones across open space are the most likely to bounce. (Symbol: the ender pearl. It fires on right-click, so the vanilla right-click action still happens too.)
- Classics → **Water Walker** — walk on the surface of water. It holds you at the top instead of letting you sink, and — so even a vanilla / no-anticheat server doesn't *falsely* bounce you — it keeps your feet just **in** the surface (wetted, so the server never starts its "you're flying" timer) with a small natural bob rather than a rigid float. Sneak to dive; it yields to real flight/elytra. Client-side, so a dedicated movement anticheat can still tell.
- **Anti-detection hardening** — every rotation any aim-based assist emits (Aim Assist, Strafe pivot, Anchor) is snapped to a per-session simulated mouse GCD, carrying the sub-unit remainder between frames, so deltas land on the same integer grid a real mouse produces (the rotation-validity check most server anti-cheats run). Triggerbot and Aim Assist also verify line-of-sight: the trigger refuses to swing through a wall (both fire paths go through the block-aware crosshair or a terrain raycast), and the aim assist nearly lets go when its target slips behind cover instead of laser-tracking through it. Triggerbot reach is held under the 3.0 server limit, fires only after a settle dwell, and follows the vanilla attack→swing packet order. Strafe Assist now repositions you for real through the **movement input system** — each hit publishes a short side-step (plus optional back) that's applied like a genuine A/D + S tap, so the server sees ordinary input-driven motion with nothing to flag; the old velocity-injection backstep (which diverged from the server's movement prediction) is gone, and the GCD'd head pivot still rides on top. Scaffold never changes yaw or pitch; it follows actual movement and the normal use cooldown. (Honest caveat: this closes hard, deterministic flags, but no automation can be guaranteed undetectable.)
- **Auto Jump Reset** (Combat) — when someone hits you it jumps for you to cut the knockback, the way a good PvPer jump-resets. It performs a REAL vanilla jump (the same `jump()` the game runs on space), only while you're on the ground at the moment of the hit, so the server sees nothing unusual — there's no packet to flag. The only giveaway a bot has is robotic timing, so the reaction is jittered tick-to-tick and it lets the odd hit through, like a human who doesn't nail every reset.
- **AutoMace** (Combat) — a mace-only auto-attack with visible, mouse-grid-quantized view movement toward a randomized hitbox point. Acquisition stays inside the configured range/FOV and line of sight; every attack requires both the cached and fresh vanilla block-aware rays to name the exact same player. Ground hits retain a tiered settle dwell and charge floor, while only a genuine descending mace smash uses the responsive aerial path. Shield Stun Slam can axe-tap a real blocking target, then restore the mace for the continuation without allowing an unrelated fresh target to bypass cooldown.
- **Auto Lunge** (Combat) — a one-shot spring-jump → spear-lunge on a key. **Not a toggle** and it never repeats: bind a key (none by default) and each press fires it once — sprint-jump to get airborne, throw a wind charge if you have one for extra pop, instantly swap to a Lunge spear, and **jab it (left-click) with the pitch momentarily leveled** so the lunge dashes you forward at full distance. The lunge is the spear's jab and only carries you when the view is level, so the module levels the pitch for the swing and restores it the same frame — the camera doesn't visibly move and never looks down. Needs a Lunge spear and **at least 3 hunger bars** (the lunge costs hunger); won't fire while gliding, riding, or in water. Movement keys release the instant it ends.
- Session restore when ProFPS is disabled.

## Build

```sh
./gradlew build
```

The playable mod jar is emitted to `build/libs/profps-1.0.0.jar`.
